# APC

Repositório dedicado às atividades e exercícios desenvolvidos na disciplina de Algoritmos e Programação de Computadores (APC) da Universidade de Brasília (UnB).

## Informações

- Aluno: Calebe Alves
- Semestre: 1º Semestre
- Linguagem utilizada: Python 3

## Objetivo

- praticar lógica de programação;
- desenvolver soluções utilizando Python;
- organizar exercícios acadêmicos;
- praticar documentação em Markdown;
- melhorar utilização de Git e GitHub.

## Atividades

1. Ordenação de três números
2. Soma e contagem de números maiores que 10
3. Leitura de números até condição de parada
4. Somatório de números pares
5. Somatório de pares utilizando repetição
6. Busca de caracteres em texto
7. Cálculo de média ponderada
8. Sistema de menu com funções
9. Extração de caracteres com funções
10. Manipulação de palavra e formatação
11. Ordenação de notas de candidatos
12. Expressão lógica booleana

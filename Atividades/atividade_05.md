# Questão 05

## Enunciado

Faça um programa que leia um número inteiro positivo e calcule a soma de todos os números pares de `2` até esse valor utilizando estrutura de repetição.

Ao final, o programa deve exibir o resultado do somatório.

### Exemplo

Entrada:
```txt
10
```

Saída:
```txt
30
```

### Explicação

Os números pares somados foram:

```txt
2 + 4 + 6 + 8 + 10 = 30
```

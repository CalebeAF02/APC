# Questão 08

## Enunciado

Desenvolva um programa que simule um menu de sistema utilizando funções.

O programa deve apresentar as seguintes opções:

```txt
1 - Cadastramento
2 - Consulta
3 - Listagem
4 - Fim
```

Para cada opção selecionada, o sistema deverá:

- chamar uma função correspondente;
- exibir uma mensagem indicando a opção escolhida;
- retornar ao menu principal após a execução;
- permitir que o usuário continue navegando até decidir finalizar o programa.

### Exemplo

Entrada:
```txt
1
```

Saída:
```txt
Olá você acessou a opção 1
```

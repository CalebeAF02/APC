# Questão 07

## Enunciado

Faça um programa que calcule a média ponderada de um aluno.

O programa deve:

- ler 8 notas;
- ler o peso correspondente de cada nota;
- calcular a média ponderada utilizando os pesos informados;
- armazenar os valores em uma estrutura de lista;
- exibir a média final formatada com duas casas decimais.

### Fórmula

A média ponderada deve ser calculada por:

```txt
média = soma(nota × peso) / soma(pesos)
```

### Exemplo

Entrada:
```txt
Nota: 10    Peso: 1
Nota: 9.5   Peso: 2
Nota: 8.5   Peso: 1
...
```

Saída:
```txt
A media é : 6.85
```

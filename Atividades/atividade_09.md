# Questão 09

## Enunciado

Desenvolva um programa que leia uma palavra, uma quantidade de caracteres a serem extraídos da esquerda para a direita e uma opção de formatação.

O programa deve:

- receber uma palavra digitada pelo usuário;
- receber a quantidade de caracteres que deverão ser extraídos;
- verificar a opção escolhida pelo usuário;
- caso o usuário digite `1`, executar uma função relacionada à exibição em maiúsculo;
- caso o usuário digite `A`, executar outra função alternativa.

O programa deve utilizar funções para tratar cada opção escolhida.

### Exemplo

Entrada:
```txt
Digite uma palavra, a quantidade de caracteres e a opção:
python 3 1
```

Saída:
```txt
ok1
```

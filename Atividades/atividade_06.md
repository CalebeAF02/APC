# Questão 06

## Enunciado

Desenvolva um programa que leia um texto e um caractere informado pelo usuário.

O programa deve:

- procurar todas as ocorrências do caractere dentro do texto;
- informar as posições em que o caractere foi encontrado;
- caso o caractere não exista no texto, exibir uma mensagem apropriada;
- permitir que o usuário execute novas pesquisas até decidir encerrar o programa.

### Exemplo

Entrada:
```txt
Digite um texto: banana
Digite um caractere: a
```

Saída:
```txt
Encontrados os caracteres no texto nas posições:
- posição 2
- posição 4
- posição 6
```
